# M5-E RPC resource limits

Workstream 1 passed: formatting/typecheck/lint and 152 service tests (134 baseline + 18 new). Existing discovery recovery and restart behavior remains green. Raw results: evidence/milestone-5/m5e/ws1-final-check.log.

A shared dependency-free BoundedReadHttp now serves the contract RPC transport, native evidence RPC and finalized NEAR Data archive. It uses a fixed-capacity buffer and caps decompressed chunks while reading, checks advertised length only as an optimization, cancels oversize/aborted streams, checks a monotonic deadline even under empty-chunk floods, decodes UTF-8 strictly, and bounds JSON nesting before parsing. Misleading or absent Content-Length cannot bypass streaming caps. Callers are exclusively read-only; no transaction submission client was added.

Per reused client defaults: 4 MiB response, 10 s request/body deadline, 15 s total budget including queue/retries, 4 active logical reads, 32 queued reads, 2 attempts (archive retains configured 1–5 attempts), 100 ms exponential backoff with bounded jitter, JSON depth 64. Active slots cover retry/backoff to prevent retry storms; queued work expires/cancels and queue overflow fails immediately. Constructor limits are validated and capped; no unbounded queues/dependency added. Defaults intentionally reject unusually large legitimate blocks/evidence rather than silently allocating or skipping them. Limits can be raised only within hard caps after review.

Native observation defaults: 256 receipt outcomes, depth 32, 800 logical RPC calls, 15 s traversal deadline, 4 simultaneous lookups, 2 MiB aggregate returned JSON per source. Call budget covers up to 256 receipt lookups plus two header checks per distinct block and fixed views. Two source bundles remain below the existing 8 MiB persisted decision cap. Each observation's own deadline cancels requests and stops scheduling new lookups. Duplicate, cyclic, disconnected or missing references fail closed. The current worker observes one attempt per explicit call; no batch scheduler or background worker is added.

Recovery defaults: 100 pages / 30 s per recoverRange invocation; event pages at most 1000 and archive blocks per page remain configured/bounded. Limit failures preserve the last atomically committed page cursor, never promote an incomplete page, and allow explicit restart/resume. A stalled custom source is raced against cancellation; real HTTP is separately deadline-bounded. These checks do not treat absent evidence as failed token delivery or authorize another payout.

Classified errors distinguish timeout, cancellation, unavailable network, rate limit, malformed/RPC response, wrong network, incomplete finality, inconsistent graph and resource limits. Only timeout/network/429/transient server reads are retried. Malformed JSON, RPC semantic errors and resource limits are not retried. Observation failures remain ManualReview with an incomplete-observation category and no recovery authority.

Tests include actual gzip/chunked/slow/terminated local HTTP responses, stream cancellation, incorrect lengths, saturated/aborted queues, retry exhaustion/recovery, graph limits, and checkpoint/page/deadline recovery across a repository restart. An initial new checkpoint fixture used mismatched provider metadata; it was corrected, not the production validator. That initial failed test log is retained.
